Multi-page Application

So far we've only touched a single index.html file. That works, and a whole site could technically live in it, but no real website is developed in one .html file.

Browsers support multi-page sites natively: every .html file you visit is its own page. The <sidebar> links to a second one, pages/about-me.html, next to the index.html in the root.
