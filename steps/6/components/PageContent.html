Stylecheat

All browsers ship browser default styles, which make a website behave differently at a fundamental level depending on which browser it's viewed in. The usual answer is a CSS reset, which makes the behaviour the same across browsers.

Stylecheat has a reset built in, and then styles the elements themselves. Headings get a serif font in the page's primary colour, and paragraphs and lists get a comfortable size, line height and line length, with even space between them.

An <hr> becomes a thin line that fades out at both ends, and <code> gets a monospace font in a soft box. The HTML stays plain, and the page has no CSS of its own.
