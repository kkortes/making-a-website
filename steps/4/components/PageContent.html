Vibe

Vibe now runs in the page, and the content moved out of it: index.html nests a <component> for components/PageContent.html, which holds this content, inside one for components/Layout.html, which puts it in the <main> through its <slot>. Components can hold other components, so any page can share the same layout.

Vibe's reactivity rests on two browser features. A JavaScript Proxy wraps the page's state, so every change to it is noticed and only the parts of the page that read that value update. A MutationObserver watches the page itself, so markup added later is picked up and markup that's removed is cleaned up.
