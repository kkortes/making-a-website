Single-page Application

In step 7 every click in the <sidebar> loaded a whole new document. Now the browser loads one document, and moving between pages only swaps the page's content inside it.

Since the document stays loaded between pages, the site can do things a multi-page site can't: show a loading indicator while the next page is on its way, or keep an mp3 playing while you navigate, where a page load would cut it off.

Three things changed: "spa": true in package.json tells Vibe's compiler to build the site as a single-page application, index.html moved into pages/ next to about-me.html, since the compiler writes the one document every address serves itself, and the links point to the routes the compiler names after the page files (/ and /about-me), which Vibe's router takes over.

The site is still built the MPA way: every page is its own full .html file in pages/, with its own <head> and <Layout>, and the compiler makes the single page out of them.
