Reactivity

Until now every repeated thing was written out by hand: each link in the <sidebar>, each card on about-me.html. Now the site's first JavaScript file, state.js, holds them as data, and Vibe renders the markup from it: <!-- each pages as link --> writes one link per page, and @[link.title] shows a value.

The state is live, too. An event handler like oninput="$.guest.name = this.value" changes it, and every binding that reads it updates on its own. Try it below.
