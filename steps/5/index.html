Stylecheat

All browsers ship browser default styles, which make a website behave differently at a fundamental level depending on which browser it's viewed in. The usual answer is a CSS reset, which makes the behaviour the same across browsers.

Modern CSS frameworks such as Tailwind have this built in. I built Stylecheat in response to those frameworks and the bloat they bring: one stylesheet with a reset and typography, so plain HTML looks good as it is. This page is the same HTML as before, now rendered with Stylecheat's typography.
