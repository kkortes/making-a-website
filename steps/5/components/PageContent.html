Compiled

The <component>s in index.html became <Layout> and <PageContent>, tags named after their files in components/. Only Vibe's compiler understands them: it puts both into the page ahead of time, so the browser no longer has to fetch them.

package.json holds the compiler's settings under vibe-compiler, where componentsAsIs set to false has it put components into the page rather than leave them for the browser to fetch.
